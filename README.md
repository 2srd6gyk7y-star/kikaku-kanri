# 企画管理ツール

れんと・ひなぎの2人で企画と台本を共有するためのWebツール。

## できること

| 機能 | 内容 |
|---|---|
| 企画の共有 | ログインした2人が同じ一覧を見る |
| 新規追加・編集 | どちらでも可能 |
| 承認 | **ひなぎさんだけ**「承認する」ボタンが出る |
| 区分 | グループ / 個人 の2択 ＋ 出演メンバーを自由に選択 |
| 動画の形式 | ショート / 横動画 を選択 |
| 参考動画 | URLを登録。「参考動画なし」チェックでURL欄はオフ |
| フィルタ | 区分（グループ / 個人）・形式（ショート / 横動画）・状態（未承認 / 承認済み）＋ 検索<br>特定メンバーで絞りたいときは検索窓にメンバー名を入れる |
| PNGでDL | 企画を1枚のPNG画像に書き出す |
| 更新履歴 | 誰がいつ何をしたかを画面下に表示。「履歴を消す」で全消しできる（企画は消えない） |

### 区分の決め方

1. **区分**を グループ / 個人 から選ぶ
2. **出演メンバー**をチェックする。グループでも個人でも、1人でも複数人でも自由

「全員」の一括チェックはグループのときだけ出ます。
最低1人は必要で、0人だと「出演メンバーを1人以上選んでください。」で止まります。
| LINE通知 | 追加・編集・承認時に公式LINEへ通知（環境変数を入れると有効） |

承認済みの企画を編集すると、自動で「未承認」に戻ります（もう一度ひなぎさんの確認が要る）。

### メンバーの色

| メンバー | 色 | | メンバー | 色 |
|---|---|---|---|---|
| ひなぎ | 水色 `#3fc6ea` | | ゆめち | ピンク `#ff5fa2` |
| れんと | 赤 `#e5493e` | | ぎる | 青 `#3a6fe0` |
| つばき | 紫 `#a865e8` | | くろば | 緑 `#25b566` |

画面のフィルタ・バッジ・チェックボックス、PNGまで同じ色で統一しています。

### PNGに載る内容

```
タイトル              [グループ] [ひなぎ] [ゆめち] [ショート]
────────────────────────────────
台本
…
```

背景は白一色。出演メンバーは名前のまわりの**縁の色**で見分けます。
グループ企画には**金色の「グループ」タグ**が付きます（個人企画にはタグなし＝金色が無ければ個人）。
グループで全員が出るときは、メンバー名を並べず **金色「グループ」＋黒の「全員」** の2枚にまとめます。

```
全員で罰ゲーム耐久        [グループ] [全員] [横動画]
                            ↑金色    ↑黒
```

ファイル名は **`タイトル【出演メンバー】.png`** で統一されます。

| 企画 | ファイル名 |
|---|---|
| 個人・ひなぎ＋ゆめち | `コンビニ検証【ひなぎ・ゆめち】.png` |
| 個人・つばき | `つばきの朝ルーティン【つばき】.png` |
| グループ全員 | `全員で罰ゲーム耐久【グループ】.png` |
| グループ・一部 | `ひなぎとぎるの検証【ひなぎ・ぎる】.png` |

タイトルが1行で収まらないとき（＝長いタイトル）や、メンバーが多くて横に並べられないときは、
出演メンバーがタイトルの下の行に回り込みます。

```
深夜3時のコンビニで店員さんの
推し商品を当てるまで帰れません
[つばき] [くろば] [ショート]
────────────────────────────────
台本
…
```

載るのは **タイトル・出演メンバー・動画の形式・台本** のみ。
参考動画URL、承認状態、作成者・更新者、出力日時は載りません。

## 1. ローカルで動かす（動作確認用）

`起動.bat` をダブルクリック。ブラウザで `http://127.0.0.1:5057` が開きます。

- 最初に「れんと」か「ひなぎ」を押すだけでログインできます（パスワードなし）
- データは `data/plans.db`（SQLite）に保存されます

初回だけ、必要なライブラリを入れてください。

```bash
pip install -r requirements.txt
```

---

## 2. クラウドに置いて2人で共有する

無料の **Render**（アプリ本体）＋ **Supabase**（データベース）の組み合わせが一番手間が少ないです。
Render の無料プランはファイルが消えるので、データベースは必ず外に置きます。

### 2-1. データベースを用意（Supabase）

1. https://supabase.com/ で新規プロジェクトを作成
2. Project Settings → Database → **Connection string (URI)** をコピー
   （`postgresql://postgres:パスワード@....supabase.com:5432/postgres` の形）

### 2-2. GitHubに上げる

このフォルダをそのままGitHubのプライベートリポジトリにpushします。
`.gitignore` があるので `data/` と `.env` は上がりません。

### 2-3. Renderにデプロイ

1. https://render.com/ で New → Web Service → 上のリポジトリを選択
2. `render.yaml` を自動で読んでくれます（読まない場合は手入力）
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app --workers 2 --threads 4 --timeout 60`
3. Environment に以下を設定

| キー | 値 |
|---|---|
| `SECRET_KEY` | 長いランダム文字列（Renderの Generate でOK） |
| `DATABASE_URL` | 2-1でコピーした接続文字列 |
| `APP_BASE_URL` | デプロイ後のURL（例 `https://kikaku-kanri.onrender.com`） |

4. デプロイ完了後のURLをひなぎさんに共有。スマホのホーム画面に追加すると使いやすいです。

> **注意**：ログインはパスワードなし（名前を選ぶだけ）なので、**URLを知っている人は誰でも中身を見られます。**
> URLは2人の間だけで共有してください。もし外部に漏れて困る場合は、合言葉を戻すこともできます。

**データはまっさらな状態で始まります。** ローカルの `data/` は `.gitignore` で除外されているのでアップロードされません。
ローカル側でテスト用の企画や履歴が残っていても、クラウドには一切引き継がれません。

> 無料プランは15分アクセスがないとスリープするので、最初の1回だけ表示に20〜30秒かかります。

## 3. LINE通知を有効にする（追々）

コードはもう入っています。環境変数を足すだけで動きます。

1. [LINE Developers](https://developers.line.biz/) で作成済みの公式アカウントのチャネルを開く
2. Messaging API設定 → **チャネルアクセストークン（長期）** を発行
3. Render の Environment に追加

| キー | 値 |
|---|---|
| `LINE_CHANNEL_ACCESS_TOKEN` | 発行したトークン |
| `LINE_TO` | 送信先の userId / groupId。**空でもOK**（空なら友だち全員へブロードキャスト） |

通知が飛ぶタイミング：企画の追加 / 編集 / 承認 / 承認取消。
未設定のあいだは何も送らず、アプリの動作にも影響しません。

## 4. メンバーやユーザーを変えたいとき

`app.py` の上のほうを直します。

```python
# ログインできる人。can_approve が True の人だけ承認ボタンが出る
USERS = {
    "rento":  {"name": "れんと", "can_approve": False},
    "hinagi": {"name": "ひなぎ", "can_approve": True},
}

# メンバーと表示色。ここを直すと画面・PNGの色がまとめて変わる
MEMBERS = [
    {"name": "ひなぎ", "color": "#3fc6ea"},
    {"name": "れんと", "color": "#e5493e"},
    ...
]
```
